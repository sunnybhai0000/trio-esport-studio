# Trio Esport Studio

Static HTML/CSS/JS esports website.

## Structure
- index.html
- style.css
- script.js
- assets/

## Cloudflare Pages
This project requires no Node.js or build command.

When connecting the GitHub repository to Cloudflare Pages:
- Framework preset: None
- Build command: leave empty
- Build output directory: `/` (or root directory)

The site can be deployed directly from the repository.
